# Newton's First Law

A box stands on a grass field and any number of forces push it along the ground. When the forces cancel out, the net force is 0 and the box keeps the velocity it has: it stays at rest, or it glides on at the same speed. That is Newton's first law. When they don't cancel out, the velocity changes by a = Fnet / m every second. There is no friction in this version.

This is the Godot (C#) version of the Octave prototype on the prototypes branch, [Prototypes/Simulations/Classical Mechanics/NewtonsFirstLaw](https://github.com/StoimenRadev/AstPIE/tree/prototypes/Prototypes/Simulations/Classical%20Mechanics/NewtonsFirstLaw). Every version of the Octave prototype becomes one version here (see Versions.md). To run it, open Simulations/project.godot in Godot 4.7.2 (.NET), open NewtonsFirstLaw.tscn and press F6.
